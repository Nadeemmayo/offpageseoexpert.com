# offpageseoexpert.com

Static site for OffPage SEO Expert, hosted on GitHub Pages (Jekyll for the blog only).

- `assets/css/site.css`, `assets/js/site.js` — shared design system and scripts
- `assets/img/` — logo (SVG/PNG), OG image, founder photo
- `assets/fonts/`, `assets/vendor/fontawesome/` — self-hosted fonts and icons
- Service pages: `complete-seo.html`, `on-page-seo.html`, `off-page-seo.html`, `technical-seo.html`, `local-seo.html`, `link-building.html`, `content-writing.html`, `web-development.html`, `custom-website.html`, `google-ads.html`, `meta-ads.html`, `facebook-ads.html`, `instagram-ads.html`, `tiktok-ads.html`
- Blog posts are managed through `/admin` (Decap CMS) into `_posts/`, rendered with `_layouts/post.html`
